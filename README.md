📖 Sobre o projeto

A SmartBlin é uma landing page moderna desenvolvida com foco em design, desempenho e experiência do usuário.

O projeto foi criado para representar uma empresa de tecnologia, utilizando uma identidade visual baseada nas cores preto, verde e branco, transmitindo inovação, confiança e modernidade.

Além de apresentar os serviços da empresa, este projeto também faz parte da minha evolução como desenvolvedor Front-end, colocando em prática conceitos de HTML, CSS e JavaScript.

---

✨ Funcionalidades

- 🎥 Hero com vídeo em tela cheia.
- 🧭 Header inteligente que aparece durante a rolagem.
- 📱 Layout totalmente responsivo.
- 🖼️ Seção de produtos com animações.
- 🎠 Carrossel de novidades desenvolvido em JavaScript.
- 💚 Interface moderna inspirada em empresas de tecnologia.
- ⚡ Navegação fluida e foco em experiência do usuário.

---

🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
